# GSX Studio

GSX Studio is a Windows desktop IDE for GSC projects. This repository is a community-maintained recovery of the original project, and is still incomplete.

## Upstream project and recovery status

The original project is [GSX Studio 2](https://github.com/shiversoftdev/GSX-Studio-2), created by SeriousHD, also known as Shiversoftdev and Serious. Its repository explains that the recovered release is missing files:

> “some stuff is missing, sorry, I recovered this from an old hard drive and do not have the files myself anymore.”

This project continues from that partial recovery. Not all missing pieces have been recovered, and some features may be missing, disabled, or nonfunctional. The solution references files and dependencies that are not included here—including the `GSXCompilerLib` and `Updater` projects, `Irony.dll`, `GSXStyling.xml`, and DevExpress libraries—so this cannot currently be built on its own.

GSX Studio was SeriousHD's work, and she passed away in 2025. This recovery is continued in appreciation of her contributions to the modding community.

## Project details

The project targets Windows, .NET Framework 4.6.2, and x86. Historical project notes describe GSC editing, autocomplete, syntax checks, project management, compilation, and platform-specific build and injection features. Because this is a partial recovery, those notes do not guarantee that every feature is available in this version.
